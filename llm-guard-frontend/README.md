# 🛡️ LLM Guard Frontend

A modern **AI Security Dashboard** built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. The application provides an intuitive interface for monitoring AI security, managing threats, visualizing security insights, interacting with AI models through a secure chat interface, and administering users within a unified cybersecurity dashboard.

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/akshunisinghk/Cybersecurity-Project.git
```

## Navigate to the frontend

```bash
cd llm-guard-frontend
```

## Install dependencies

```bash
npm install
```

## Run development server

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
